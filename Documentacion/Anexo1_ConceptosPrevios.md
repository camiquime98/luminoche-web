## Introducción

El desarrollo de aplicaciones web modernas requiere una comprensión profunda de los fundamentos arquitectónicos, metodologías de diseño y procesos de investigación que garanticen la creación de soluciones efectivas y centradas en el usuario. Esta actividad tiene como propósito explorar tres pilares fundamentales del desarrollo web: la arquitectura Cliente/Servidor, el diseño centrado en el usuario y la importancia de la investigación en el territorio para el análisis de requisitos.

A través de esta actividad, se busca que los estudiantes adquieran conocimientos teóricos sólidos que les permitan comprender cómo se estructuran las aplicaciones web, cómo se diseñan interfaces que respondan a las necesidades reales de los usuarios y cómo la investigación contextual es esencial para desarrollar especificaciones técnicas precisas. El trabajo se desarrolla mediante la revisión de material bibliográfico especializado, la participación en foros de debate y la creación de una página web informativa que consolide estos conceptos.

La metodología empleada incluye la lectura crítica de referencias académicas, la participación activa en espacios colaborativos y el desarrollo práctico de una solución web que demuestre la comprensión de los conceptos abordados. Este documento presenta la documentación completa del proceso de aprendizaje y desarrollo realizado durante la Etapa 1 del curso.

### Respuesta a las preguntas orientadoras

#### a) ¿Qué papel tiene la arquitectura Cliente/Servidor en la programación web dinámica?

La arquitectura Cliente/Servidor desempeña un papel fundamental en la programación web dinámica, ya que establece el modelo de comunicación que permite la interacción bidireccional entre el usuario y la aplicación web. Según Luján (2002), esta arquitectura divide las responsabilidades entre dos componentes principales: el cliente, representado por el navegador web, y el servidor, que procesa las solicitudes y genera respuestas dinámicas.

En la programación web dinámica, esta arquitectura permite que las aplicaciones respondan a las acciones del usuario en tiempo real. El cliente puede enviar datos mediante formularios, peticiones AJAX o WebSockets, mientras que el servidor procesa esta información, consulta bases de datos y genera respuestas personalizadas. Como señala el blog de infraestructura de red (2019), este modelo facilita la escalabilidad, ya que un solo servidor puede atender múltiples clientes simultáneamente, optimizando el uso de recursos.

Además, la arquitectura Cliente/Servidor en web dinámica permite la separación de responsabilidades: el cliente se encarga de la presentación y la interacción con el usuario, mientras que el servidor maneja la lógica de negocio, el acceso a datos y la seguridad. Esta separación facilita el mantenimiento, la actualización y la escalabilidad de las aplicaciones web modernas.

#### b) ¿Qué importancia tiene la investigación en el territorio para el análisis de requisitos y especificaciones técnicas en programación web?

La investigación en el territorio es de vital importancia para el análisis de requisitos y especificaciones técnicas en programación web, ya que permite comprender el contexto real en el que se utilizará la aplicación y diseñar soluciones verdaderamente útiles y apropiadas para el entorno específico.

Según Granollers (2012), el diseño centrado en el usuario requiere una comprensión profunda de las necesidades, expectativas y limitaciones de los usuarios finales. La investigación en el territorio proporciona esta comprensión al permitir identificar características culturales, sociales y económicas particulares que influyen en cómo los usuarios interactúan con las aplicaciones web.

La investigación territorial ayuda a identificar necesidades reales que no serían evidentes sin un contacto cercano con el contexto. Por ejemplo, conocer la infraestructura tecnológica disponible, el acceso a internet y los dispositivos más utilizados en una región específica permite diseñar soluciones optimizadas para esas condiciones. Esto se traduce directamente en especificaciones técnicas más precisas, como requisitos de rendimiento, compatibilidad de dispositivos y optimización de recursos.

Además, la investigación en el territorio permite adaptar las aplicaciones a normativas locales, idiomas, formatos de fechas, monedas y otras convenciones culturales, lo cual es esencial para crear experiencias de usuario satisfactorias y cumplir con regulaciones específicas de cada región.

#### Especificaciones Técnicas

**Tecnologías Utilizadas:**
- **HTML5:** Estructura semántica del contenido (header, nav, main, section, footer)

- Efecto parallax suave en hero section

#### Aplicación de Arquitectura Cliente/Servidor

**Estructura Cliente (Frontend):**
- **HTML5:** Presenta la interfaz de usuario en el navegador
- **CSS3:** Renderiza los estilos y diseño visual
- **JavaScript:** Maneja la interacción del usuario, validaciones y peticiones

**Estructura Servidor (Backend - Simulada):**
- **Procesamiento de solicitudes:** El JavaScript simula el envío de datos al servidor
- **Gestión de datos:** En una implementación real, el servidor manejaría:
  - Inventario de productos
  - Procesamiento de pedidos
  - Almacenamiento de información de contacto
  - Autenticación de usuarios

**Comunicación Cliente/Servidor:**
- **Protocolo HTTP/HTTPS:** Para intercambio de información
- **Peticiones AJAX/Fetch:** Para comunicación asíncrona (simulada en el código)
- **Formularios:** Envío de datos del cliente al servidor
- **Respuestas del servidor:** Procesamiento y retorno de información

**Ejemplos en el Código:**
1. **Agregar al carrito:** El botón simula enviar una petición POST al servidor con el ID del producto
2. **Formulario de contacto:** Simula el envío de datos mediante método POST al servidor
3. **Carga de productos:** En una implementación real, los productos se cargarían desde una base de datos del servidor

#### Diseño Centrado en el Usuario Aplicado

**Principios DCU Implementados:**

1. **Usabilidad:**
   - Navegación clara e intuitiva con menú visible
   - Información organizada jerárquicamente
   - Botones con texto descriptivo y feedback visual
   - Formularios con labels claros y validación

2. **Accesibilidad:**
   - Estructura semántica HTML5 (header, nav, main, section, footer)
   - Navegación por teclado funcional
   - Contraste adecuado entre texto y fondo
   - Tamaños de fuente legibles

3. **Responsive Design:**
   - Adaptación a diferentes tamaños de pantalla
   - Menú hamburguesa en móviles
   - Grid flexible que se adapta al espacio disponible
   - Imágenes y contenido escalables

4. **Feedback Visual:**
   - Animaciones al hacer hover sobre elementos interactivos
   - Cambios de estado en botones (agregado, enviado)
   - Transiciones suaves entre estados
   - Indicadores visuales de interacción

5. **Jerarquía Visual:**
   - Títulos destacados con gradientes dorados
   - Información importante en tamaño mayor
   - Uso de espaciado para separar secciones
   - Colores para diferenciar elementos (productos, características, contacto)

6. **Experiencia de Usuario:**
   - Carga rápida de contenido
   - Animaciones que no distraen
   - Diseño estético y moderno que genera confianza
   - Flujo lógico de información (Hero → Productos → Características → Contacto)

#### Investigación en el Territorio para el Análisis de Requisitos

**Investigación Realizada:**

1. **Análisis de Mercado Local:**
   - Estudio de preferencias de iluminación en hogares colombianos
   - Identificación de rangos de precios aceptables en el mercado local
   - Análisis de competencia en el sector de iluminación decorativa

2. **Entrevistas con Usuarios Potenciales:**
   - Consulta sobre necesidades de iluminación nocturna
   - Preferencias de diseño (moderno, minimalista, clásico)
   - Funcionalidades deseadas (control táctil, app móvil, cambio de color)

3. **Análisis de Infraestructura:**
   - Adaptación a estándares eléctricos colombianos (110V)
   - Consideración de conectividad disponible (WiFi, Bluetooth)
   - Compatibilidad con dispositivos móviles más usados en Colombia

4. **Especificaciones Técnicas Basadas en Investigación:**
   - **Precios:** Adaptados al poder adquisitivo local (rango $89.900 - $199.900)
   - **Tecnología:** LED de bajo consumo (importante por costos de energía)
   - **Conectividad:** Opciones USB y WiFi (infraestructura disponible)
   - **Diseño:** Estética moderna que apela al mercado joven y profesional

5. **Localización:**
   - Idioma español colombiano
   - Formato de precios en pesos colombianos
   - Información de contacto con código de país (+57)
   - Referencias a ubicación (Bogotá, Colombia)

**Resultado de la Investigación:**
La investigación territorial permitió definir requisitos específicos como precios competitivos, funcionalidades deseadas por el mercado local, y diseño que se adapta a las preferencias estéticas de los usuarios colombianos. Esto se tradujo en especificaciones técnicas precisas para el desarrollo de la página web y la presentación de productos.

## Conclusiones

El desarrollo de esta actividad ha permitido consolidar conocimientos fundamentales sobre tres aspectos críticos del desarrollo web moderno, aplicándolos de manera práctica en la creación de una página web sobre luces estéticas modernas para mesas de noche.

En primer lugar, se comprendió que la arquitectura Cliente/Servidor no es solo un modelo técnico teórico, sino la base que permite crear aplicaciones web dinámicas, escalables y mantenibles. En el desarrollo de la página LumiNoche, esta arquitectura se aplicó mediante la separación clara entre el frontend (HTML, CSS, JavaScript que el usuario visualiza) y el backend (simulado para procesamiento de solicitudes, gestión de inventario y datos). Esta separación de responsabilidades facilita el mantenimiento, la actualización y la escalabilidad, siendo esencial para el desarrollo de aplicaciones web contemporáneas.

En segundo lugar, se reconoció la importancia del diseño centrado en el usuario como metodología que coloca las necesidades y expectativas de los usuarios en el centro del proceso de desarrollo. En la página desarrollada, esto se manifestó a través de una interfaz intuitiva con navegación clara, diseño responsivo que se adapta a diferentes dispositivos, feedback visual en todas las interacciones, y una jerarquía visual que guía al usuario naturalmente. Este enfoque no solo mejora la satisfacción del usuario, sino que también reduce costos de desarrollo y mantenimiento al crear soluciones más intuitivas y eficientes desde el inicio.

Finalmente, se evidenció que la investigación en el territorio es fundamental para el análisis de requisitos y especificaciones técnicas precisas. Para el desarrollo de LumiNoche, la investigación permitió identificar preferencias de diseño del mercado colombiano, rangos de precios apropiados, funcionalidades deseadas (control táctil, app móvil, cambio de color), y adaptaciones técnicas (voltaje 110V, conectividad disponible). Comprender el contexto cultural, tecnológico y regulatorio de cada región permite diseñar aplicaciones que sean verdaderamente útiles y apropiadas para sus usuarios finales, evitando soluciones genéricas que no responden a necesidades específicas.

La creación de la página web sobre luces estéticas permitió aplicar estos conceptos metodológicos de manera práctica, desarrollando habilidades en HTML5, CSS3 y JavaScript, mientras se consolidaba la comprensión teórica de los temas abordados. El diseño moderno y estético con paleta oscura y acentos dorados, junto con animaciones suaves y efectos visuales, demuestra cómo la metodología técnica puede combinarse con estética atractiva para crear experiencias de usuario exitosas.

El proceso de documentación y participación en foros de debate enriqueció el aprendizaje mediante el intercambio de perspectivas con compañeros. Este trabajo sienta las bases para etapas posteriores del curso, donde se aplicarán estos conceptos en el desarrollo de soluciones web más complejas y específicas para problemáticas reales, siempre manteniendo la metodología de Cliente/Servidor y diseño centrado en el usuario como fundamentos del desarrollo.
