## Descripción del Proyecto

Este proyecto consiste en una página web informativa desarrollada en HTML5, CSS3 y JavaScript que presenta información sobre:

- Arquitectura Cliente/Servidor en el desarrollo web
- Diseño centrado en el usuario
- Importancia de la investigación en el territorio para el análisis de requisitos

---

## Características de la Página Web

- ✅ Diseño moderno y profesional
- ✅ Responsive (adaptable a móvil, tablet y desktop)

- ✅ Menú interactivo para móviles

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica del contenido
- **CSS3**: Estilos, diseño responsivo y animaciones

## Cómo Usar

1. Abrir el archivo `index.html` en un navegador web moderno
2. Navegar por las diferentes secciones usando el menú superior
3. La página es completamente funcional sin necesidad de servidor

---

## Requisitos del Navegador

- Chrome (recomendado)
- Firefox
- Safari
- Edge
- Cualquier navegador moderno con soporte para HTML5, CSS3 y JavaScript ES6+
